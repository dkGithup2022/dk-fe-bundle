# fe-extract-data-inventory 실행 예시

Peeple(지역 모임 · 이벤트 서비스) 을 이 체인으로 만든 실제 실행에서 발췌했다. 실행일 2026-09-22.

## 입력

- 화면 이미지 26장

## 사람이 정한 것

- 애매한 것(댓글 · 좋아요 · 멤버 모집 글 · 게시판 · 장소 · 이벤트 회차)과 소속 미정 필드 4개는 다음 단계에서 결정하기로 넘겼다

## 산출물

### 데이터 목록 (앞부분)

출처: `docs/data-inventory.md`

```markdown
# 데이터 목록

작성: 2026-09-22

## 화면

폴더에 있는 파일명을 그대로 적는다. 폴더 위치는 적지 않는다.

- s01-home.png: 홈. 참석 확인 배너, 지역·카테고리 필터 칩, 이야기 카드와 후기 카드가 섞인 피드, 검색·알림, 글쓰기 FAB
- s02-groups.png: 모임 찾기. 검색(이벤트·지역), 카테고리 탭, 정렬, 모임 카드(이름·지역·멤버 수·팔로우·최근 기록), 멤버 모집 글 목록, 모임 만들기
- s03-story.png: 이야기 뷰어. 표지, 라벨(이야기 · 모임 주최), 제목, 주최자들, 발행 시각, 본문(글·사진), 하단 모임 카드, 연결 이벤트, 좋아요·댓글 수, 참석 신청
- s04-group.png: 모임 페이지(방문자). 커버, 이름, 지역·멤버 수·가입 방식 배지, 소개, 팔로우·가입 신청, 탭(아카이브·이벤트·게시판·멤버), 아카이브 목록
- s05-apply.png: 지원서 작성. 모임 요약, 프로필 자동 채움(닉네임·지역·관심사), 운영자 질문 답변, 제출, "신청 대기중" 안내
- s06-attend.png: 참석 확인 시트. 후기 유도, 첨부될 이벤트, 후기 남기러 가기 / 다음에
- s07-review.png: 모임 후기 작성. 이벤트 자동 첨부, 사진, 한두 줄, 공개 범위, 제출
- s08-write.png: 이야기 작성. 표지, 제목, 부제, 본문 블록(글·사진), 블록 도구(사진·제목·인용·구분선), 임시저장, 발행
- s09-publish.png: 발행 설정. 이벤트 연결(선택), 팔로워 알림 토글, 발행
- s10-writesheet.png: 글쓰기 시트. 후기 남기기 / 모임 관련 글 작성 선택
- s11-reviewpick.png: 후기 선택 시 최근 참석 이벤트 목록(라디오)
- s12-writepick.png: 글 작성 선택 시 어느 모임 이름으로 쓸지(라디오)
- s13-create1.png: 모임 만들기 1. 이름, 한 줄 소개, 소개글, 대표 사진
- s14-create2.png: 모임 만들기 2. 상위·하위 카테고리, 위치 검색·지도 핀·주소
- s15-create3.png: 모임 만들기 3. 지원서 받기 토글, 질문 목록
- s16-createdone.png: 완료. 첫 이야기 / 첫 이벤트 / 나중에
- s17-5a.png, s18-5b.png: 이벤트 탭 A안·B안. s26 합본으로 대체됨
- s19-5c.png: 이벤트 탭 C안. 제외 확정 (디자인 노트)
- s20-groupowner.png: 모임 페이지(운영자). 내가 운영 배지, 예정 이벤트 수, 이벤트 등록·운영 콘솔, 새 지원서 배지
- s21-regmodal.png: 등록 방식 모달. 정기 모임 / 달력에서 날짜 골라
- s22-regular.png: 정기 모임 등록. 이름, 요일, 시작·소요, 위치 지정, 정원 제한 없음, 언제부터, 생성될 회차 미리보기
- s23-calreg.png: 달력 직접 등록. 이름, 날짜, 시작·소요, 위치, 정원 n명, 대기 안내
- s24-oldnorepeat.png, s25-eventrepeat.png: [구안] 표시. 제외
- s26-eventtab.png: 이벤트 탭 확정(달력 + 예정·지난 목록, "매주" 배지)

## 논리적 도메인

- 유저: 서비스 사용자. 닉네임·지역·관심사 프로필. 작성자·지원자·참석자·팔로워로 등장
- 모임: 이름·지역·소개·카테고리·위치·가입 방식을 가진 단위. 이벤트와 이야기를 발행
- 이벤트: 모임이 여는 일정. 단발 또는 정기(회차가 여러 개 생김)
- 이야기: 모임 이름으로 발행하는 긴 글. 표지·제목·본문 블록·연결 이벤트
- 모임 후기: 참석한 이벤트에 남기는 사진과 한두 줄
- 지원서: 심사제 모임에 내는 가입 신청. 프로필 + 질문 답변 + 상태
- 팔로우: 유저 → 모임 관계
- 참석: 유저 → 이벤트 관계. 참석 또는 대기
- 멤버십: 유저가 모임의 멤버 또는 운영자
- 알림: 홈 상단 알림 점으로만 보임. 목록 화면 없음
…(이하 생략)
```

### 애매한 것

출처: `docs/data-inventory.md`

```markdown
## 애매한 것 (사용자 판단 필요)

도메인인지 기능 데이터인지 가르기 어려운 것. 도메인 후보도 확신이 없으면 여기에 둔다.

- 댓글: 뷰어 하단 좋아요 옆 "12" 가 댓글 수로 보임. 댓글 화면 없음 — s03-story.png. 후보: 도메인 / 이야기의 카운트 필드
- 좋아요: 유저 → 이야기 관계 — s03-story.png, s04-group.png. 후보: 도메인(팔로우처럼) / 이야기의 카운트 필드
- 멤버 모집 글: 모임 찾기 아래 목록. 이야기의 한 종류인지 별도 글인지 — s02-groups.png. 후보: 이야기 / 별도 도메인
- 게시판 글: 탭만 있고 화면 없음 — s04-group.png. 후보: 도메인 / 이번엔 제외
- 장소: 검색 + 지도 핀 + 주소. 재사용되면 독립 — s14-create2.png, s22-regular.png, s23-calreg.png. 후보: 모임·이벤트의 필드 / 도메인
- 이벤트 회차: 정기 모임이 만드는 개별 날짜 — s22-regular.png 미리보기, s26-eventtab.png. 후보: 이벤트 자체 / 이벤트 아래 별도 항목
```
